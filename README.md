# Fale e Leia

Aplicativo infantil de alfabetização. A criança fala uma palavra, o app mostra por escrito em letras grandes e maiúsculas, e permite ouvir letras e sílabas.

- 🎤 Fale uma palavra
- ⌨️ Digite uma palavra
- 🔤 Toque numa letra para ouvir
- 🧩 Toque numa sílaba para ouvir
- 🔊 Ouça a palavra de novo

Funciona no Chrome e no Safari. O reconhecimento de voz exige HTTPS e permissão do microfone.
